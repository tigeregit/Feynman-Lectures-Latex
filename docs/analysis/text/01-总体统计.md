# 01 总体统计：规模、段落长度、句长

> 生成工具：`tools/audit_text.py`（`python3 tools/audit_text.py` 可完整复现）。
> 统计对象：`Chapters/VolumeI/Chapter1..52.tex`、`VolumeII/Chapter1.tex`、`VolumeIII/Chapter1.tex`，分支 `feat/reading-efficiency`。

## 结论摘要

1. **规模与结构**：全书 54 章、292 个 `\section`（另 3 个 `\section*`）、12,987 行、原始汉字 488,281 个；清洗后**正文段落 2,080 个**，正文汉字 460,288 个，总字数（汉字+西文词）462,271。全书**只有 1 个 `enumerate`、0 个 `itemize`**，即结构上完全没有列表。
2. **段落偏长**：段落字数均值 **222**、中位 **190**、p90 **417**、最长 **997** 字；**503 段（24.2%）超过 300 字**，其中 108 段超过 500 字、0 段超过 1000 字；另有 **13 节纯文字墙**（>1500 字且无图/表/展示公式，见 04）。
3. **句子偏长**：句长均值 **35** 字、中位 **31**、p90 **62**、p99 **100**、最长 **238** 字；超过 80 字的句子 **412** 句、超过 150 字的 **9** 句、超过 200 字的 **1** 句（清单见 05）。
4. **强调断层**：`\uwave` 共 **455** 处（正文内 447 处，其余在图表标题里；第 44 章的 7 处全在表格标题内），正文强调只分布在 10 章（第一卷 1–10 章），其余 44 章零正文强调；对比图 294 幅、表 27 张、展示公式 1058 个，“长段 + 长句 + 无重点标记”是大多数章节的默认状态（见 05）。
5. **列表化机会**：正文中"第一/第二""（1）（2）""首先/其次/最后"等枚举标记大量存在，但都以散文形式写成；`03-列表化候选.csv` 给出可直接改造的段落清单，`02-长段落清单.csv` 给出 503 个 >300 字段落及建议切分点。这两份清单是阅读效率改造的优先工作面。

## 一、统计口径

| 指标 | 定义 |
|---|---|
| 章 / 节 | `\chapter` / `\section` 命令数；`\section*` 单独计数、单独列（参考文献、小结） |
| 原始空行块 | LaTeX 源文件中被空行分隔的块（含图、表、公式、标题等结构块），用于和旧粗口径对照 |
| **正文段落** | 空行块中去掉图/表/展示公式/标题/脚注等结构内容后仍含汉字的块；块内若有 `\item` 按列表项再切分；纯英文参考文献条目不计 |
| **字数** | 汉字数 + 西文词数（连续拉丁字母串、数字串各计 1 词）；标点、行内公式、`\ref` 编号不计；同时给出"汉字数"备查 |
| **句** | 段落正文按 `。！？` 切分、且至少含 1 个汉字的片段；句子不跨段 |
| 展示公式 | 顶层 `equation/equation*/align/align*/flalign/gather/multline/eqnarray` 环境与 `\[...\]`；`aligned/split/cases` 等公式内部结构不重复计 |
| 图 / 表 | 图 = `figure`+`wrapfigure`；表 = `table`+`longtable`（另报 `tabular` 数） |
| 内联公式 | 成对的 `$...$` 数 |
| 行号 | 源文件 1-based 行号；行数按换行符计（与 `wc -l` 一致） |

> 与旧粗口径的差异：旧口径把结构块也当成"段落"（约 2.4k 块），并把 `\footnotesize` 误计为脚注（"136 个脚注"实为 `\footnote` 字符串出现数）；本表只统计清洗后的正文段落与真实脚注。详细对照见文末"六"。
