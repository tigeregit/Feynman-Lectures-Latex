# docs/analysis/text —— 文本可读性审计（可复现）

本目录是《阅读效率提升方案》的**文本侧量化证据**：段落/句子长度、列表化机会、纯文字墙、强调缺失、中英段落对照。全部数字由 `tools/audit_text.py` 生成，可复现。

## 文件索引

| 文件 | 内容 | 主要用途 |
|---|---|---|
| `01-总体统计.md` | 全书/每章规模、段落长度分布、句长分布、每章明细、与旧口径对照 | 方案的总量证据 |
| `02-长段落清单.csv` | 全书 >300 字段落（>500 标 P0）、建议切分点与理由 | 优先改造清单 |
| `03-列表化候选.csv` | “第一/第二”“（1）（2）”“首先/其次/最后”等枚举式段落、建议列表类型 | 列表化改造清单 |
| `04-纯文字墙节.csv` | >1500 字且无图/表/展示公式的节、建议改造手段 | 按节组织改造 |
| `05-强调与长句.md` | `\uwave` 按章分布、>80 字长句全清单、内联公式最密的节 | 强调规范与断句清单 |
| `06-中英段落对照.csv` | 每章中/英段落数（含区间）、疑似合并位置、对齐质量 | 中英段落结构对照，核实“译文合并段落”问题 |

## 复现命令

在仓库 `Feynman-Lectures-Latex/` 根目录执行：

```bash

python3 tools/audit_text.py --check

# 指定英文抓取目录（默认 _attachments/build-feynman/audit/en，本地忽略目录）
python3 tools/audit_text.py --en-dir _attachments/build-feynman/audit/en
```

## 统计口径（简述）

- **正文段落 2,080 个**：LaTeX 源文件按空行分块，去掉图/表/展示公式/标题/脚注等结构内容后仍含汉字的块；块内 `\item` 按列表项再切分；纯英文参考文献条目不计。
- **字数** = 汉字数 + 西文词数（连续拉丁字母串/数字串各计 1 词）；标点、行内公式、`\ref` 编号不计。
- **句** = 段落正文按 `。！？` 切分且含汉字的片段。
- 详细定义见 `01-总体统计.md` 第一节“统计口径”。

## 各文件的判定规则

### 02 长段落（>300 字）

- 阈值：字数 >300；其中 >500 标为 `P0`（重点段）。
- 建议切分点：目标“每段 ≤250 字”，按句末位置均匀取点，且优先落在转折/递进词（但是/因此/另一方面/首先/最后…）开头的下一句之前。
- “切分理由”按段落特征自动生成：超长段、句数多、含超长句、转折位置等。

### 03 列表化候选

检测以下标记（同一段落内或相邻连续段落之间）：

1. 中文序数（`第一，`/`第二、`/`第三：`）；
2. 括号序号（`（1）`/`(1)`）；
3. 顺序词（`首先`/`其次`/`再次`/`然后`/`最后` 中 ≥2 类）；
4. `一是`/`二是`；
5. 手工罗马序号（`\uppercase\expandafter{\romannumeralN}.`，如第 47 章，不是 LaTeX 列表）；
6. 段首数字序号（`1.`/`2.`，含跨段成序列）；
7. 分号并列（一段 ≥5 个 `；` 且句数 ≤4）。

“建议列表类型”按标记族映射为有序列表/步骤列表/要点列表/表格。

### 04 纯文字墙节

判定：节字数 >1500，且该节图数=0、表数=0、展示公式数=0（`参考文献` 节除外）。建议改造手段由规则组合：拆段、列表化、加小标题、补示意图/对照表、断句。

### 05 强调与长句

`\uwave` 按章计数；长句 = 段内按 `。！？` 切分后字数 >80 的句子，行号由清洗后的字符位置回溯到源文件行；内联公式密度 = 节内 `$…$` 对数 / 节字数 ×1000。

### 06 中英段落对照——方法与误差

英文数据来自 `_attachments/build-feynman/audit/en/I_XX.txt`（本地忽略目录，从官方 eFLP 页面用 `innerText` 抓取）。**该文本并非严格“每段一行”**：

- 正文段落被空行分隔；但**展示公式会被 MathJax 拆成一行一个符号的公式块**，行内公式也会把正文切成多行，导致公式多的章节出现大量短碎片行；
- 因此本工具先丢弃导航区、公式块、图/表标题，再把被展示公式切开的正文块按“上一块最后一行是否句末标点 + 本块是否大写开头”重建为段落。

由于重建规则对“段末是展示公式、下一段以大写开头”的情况无法完全区分，英文段落数只能给一个**区间**：

- **下界**：重建合并后的段落数（保守合并，倾向少算）；
- **上界**：含正文的空行块数（每个公式块都被当成段落边界，倾向多算）；
- 06 CSV 的“英文重建不确定度 = 上界 − 下界”列给出该章的区间宽度；宽度 >8 的章（公式密集章）其“中-英段差”不宜直接解读为合并。

对照方法：

1. 中文段落取清洗后的正文段（与 01 同口径）；
2. 用中文总字数 / 英文总词数估计换算比（本次第一卷全局比约 **1.42 汉字/英词**）；
3. 动态规划对齐（允许 1:1、2:1、3:1 合并与两侧跳过，长度偏差取对数惩罚），把“一个中文段吸收 2–3 个英文段”识别为**疑似合并**，并给高/中/低置信度；
4. 第二、三卷第 1 章为**节选试译**，英文覆盖率 <100%，其段落差是“未译完”而非合并。

> 本次全局换算比 = 第一卷正文总字数 / 第一卷英文词数 ≈ 1.421。

**与背景基线的口径冲突（重要）**：任务背景给出的“多数章节约 15% 的段落被合并、ch25/ch23/ch21/ch19 合并严重”，在本次严格口径下**没有复现**：

- 第一卷中文正文段落 2,060 个（对照时把 3 个列表项并为 1 个单元，共 2,058 个对照单元），英文重建段落下界 1,904 个、上界 2,444 个；中文段落数介于两者之间，**52 章中有 48 章中文段落数≥英文重建下界**，即总体上看不出系统性“段落被合并”；
- 全书检出的疑似合并共 33 处（涉及 67 个英文段），其中达到高置信度的只有 10 处（涉及 20 个英文段），逐条列在 `06b`，可人工核对；另有 7 章（I-01/I-07/I-09/I-22/I-35/I-36/I-37）中文段落数超过英文上界，说明中文拆分多于合并；
- 旧结论很可能来自把英文抓取文本里的**公式碎片/长行**当成段落的口径——公式多的章（如 I-19 上界比下界高 60%、I-23 高 43%、I-21 高 28%、I-25 高 15%），“空行文本块数”会被展示公式显著抬高，从而看起来像“中文少了很多段”；
- 具体到背景点名的四章：I-25 的**末段**确有明显合并（中文 1 段 803 字吸收了英文 3–4 段，涉及 368+ 英词，见 06b 行 200），但 I-23、I-21 本口径下没有高置信合并，I-19 有 1 处；“ch25/ch23/ch21/ch19 合并严重”只能部分成立（ch25 章末较明显），其余三章证据不足；
- 需要说明：若把英文侧上界（每一个空行文本块都算段落）当作真实段数，合并率会接近旧说法；但那会把被展示公式切开的同段续文误当段落，不可取。本报告采用的下界+区间口径更保守，结论应表述为：**在可核对的高置信样例里**存在中文合并/拆分段（见 06b），但“多数章节 15% 合并、四章严重”这一量级需要人工按 06b 行号抽样复核后再写入方案。

误差来源与量级：

- 英文段落重建在公式多的章节可能多切/少切 1–3 段（用“不确定度”列量化）；
- 中文段落按源文件空行切分：若译者把多段合并成一段且中间无空行，计为合并（正是要检测的问题）；若译者拆分段落，则表现为“中文增补/拆分段数”；
- 译文对原文的增删（脚注、译注、信息补充）会造成个别段落对齐偏移，请结合“对齐质量”“英文覆盖率”列，不要只看合并率。

## 已知局限

1. **句长口径**：分号、冒号内的分句不单独切分，因此含多个并列分句的句子会被算作一句（这恰是需要列表化的信号）；引号内引用也算在同一句内。
2. **字数口径**：行内公式与 `\ref` 编号不计字数，公式密集段落会略偏短；西文词与数字按“串”计 1 词，与中文字符不严格等长。
3. **段落口径以 LaTeX 源文件空行为准**：图/表/展示公式若独占空行块，会把前后文字分成两段（与印刷排版一致）；若译者把公式与正文写在同一块内，则算作一段。
4. **英文侧为二次重建**，不是人工段落标注；06 的合并判定请以“置信度=高”的样例为准，具体段落需人工核对 `06b` 的行号。
5. 第二、三卷仅第 1 章且为节选，全书统计由第一卷主导；不要外推到第二/三卷其他章。
6. 本工具做**文本计量**，不评价翻译质量或知识正确性；切分/列表化建议是启发式规则，需编辑人工判断。
7. 英文抓取目录是本地忽略目录，不在 git 中；若在其他机器复现 06，需要先有同一批 `en/*.txt`，否则 06 会输出“缺少英文抓取文件”。
