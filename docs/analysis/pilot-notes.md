## 3. 零删除验证（核心证据）

### 3.1 方法

`preview/content-pilot/verify_nodel.py`：

1. 从 `Chapters/VolumeI/Chapter2.tex` 抽取 §2-1 正文行（5–25）、§2-3 正文行（72–82）的**原文**；
2. 从 `ch2-pilot-body.tex` 按 `\section{...}` 切出两节**改造后正文**；
3. 对两边做同一套"可见内容字符"归一化：
   - 删除注释（`%` 之后）、LaTeX 命令名（`\foo`）、环境名（`\begin{...}`/`\end{...}`）、花括号、列表标签方括号、空白；
   - **保留**：CJK 汉字、CJK 标点、拉丁字母数字、引号/破折号等（即读者实际看到的文字）；
4. **剔除新增文字**：`\chapterintro`、`\readingpath`、`\runin`、`\enterm`、`\figsource` 的参数，`summarybox` / `conceptmap` / `figure` / `table` 环境整体，`\label` 参数；
5. 逐字符比对。退出码 0 = 一致。

> 关键点：`\term` / `\keyidea` / `\pullquote` / `\aside` / `\footnote` 的**参数内容全部计入**（它们是原文文字，只是换了呈现方式）；`\item[...]` 方括号内的原文序数词也计入。

[PASS] §2-3 量子物理学：原文 3381 字符 / 改造 3381 字符
结论：全部一致，零删除验证通过。

## 7. 风险与需人工复核点

## 8. 可推广规则清单（供全书 52 章批量改造）

| # | 规则 | 操作要点 |
|---|---|---|
| R1 | **段落 ≤250 字** | 以句末标点为界；优先在设问、转折（"但是/然而"）、总结（"所以/简言之"）处切；不拆公式、不拆括号；超长列表项在项内再切段 |
| R2 | **列表化判据** | 出现"第一/第二/第三、首先/其次/最后、其一/其二、（1）（2）、有三种办法、有如下几个、例如：A，B，C"等显式枚举 → 改列表；短词枚举（≤3 个词、无谓语）不列表 |
| R3 | **列表项保真** | 原句原标点原顺序放进 `\item`；序数词≤4 字可作 `\item[...]` 标签，更长则用 `\item \textbf{原词}…` 避免标签溢出 |
| R4 | **小标题 3–6 个/节** | 用"概念名/问题名"（≤6 字），加在段首；不改写首句；小标题不重复节标题 |
| R5 | **术语加粗** | 只标真正术语的**整章首现**；比喻词、普通名词不标；一词只标一次；定义处与首现处不一致时在 notes 说明 |
| R6 | **关键句 ≤4 处/节** | 选判断句/规律句/结论句；尽量落在句界；不整段加粗 |
| R7 | **引文块 1–2 处/节** | 只选费曼金句；必须是完整原句；放在段落末尾，避免打断论证 |
| R8 | **小结 3–5 条** | 只提炼；每条一个判断、≤40 字；不加原文没有的数字/事实/因果 |
| R9 | **导读** | 一句话定位＋3–5 条要点＋与前后章关系；并标注"本样张范围" |
| R10 | **选读 1–2 段/节** | 判据：离题但有信息量的插话（历史、人物、文化、类比延伸）；**解释正文关键信息的括注不要标选读**；隐藏后前后文仍通顺 |
| R11 | **页边注** | 脚注/括注型译者注 → `\aside`，文字原样；注意 twoside 外白、长短与浮动体冲突 |
| R12 | **每节 ≤1 张示意图** | 优先用原文比喻/分类关系；TikZ 手绘级即可；编号用 (1)(2)(3)；图注注明"非原书插图" |
| R13 | **零删除验证** | 每节改完立即跑 CJK 序列比对；新增文字必须走宏/环境（runin/chapterintro/summarybox/optional/figsource/图注），验证脚本按名单剔除 |
| R14 | **禁止顺手改错** | 原文错字、术语不一致、标点问题一律照录；勘误另立任务 |
