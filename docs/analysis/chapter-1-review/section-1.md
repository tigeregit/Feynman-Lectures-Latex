## 存疑项

以下条目我判断为“与英文有偏差但未必是错误”，或是纯译法取舍，是否改动请上游（Lead/作者）判断：

1. **L44**“正是为了要抛弃以前的谬见，或者更可能的是为了改正以前的谬见” ← “things must be learned only to be unlearned again or, more likely, to be corrected.”“unlearn”是中性的“推翻/忘记已学（近似知识）”，“谬见”把已学内容染上“错误观念”的色彩；但中文可读性尚可，改译会动风格。
2. **L55**“结果就发现了一条‘定律’” ← “So a ‘law’ was invented”。“invented”强调“人为造出（随后被证伪）”，“发现”弱化了这层意味；但“发明定律”中文略生硬，仅标注。
3. **L57**“新的定律实际上并没有什么有意义的差别” ← “makes no significant difference”。“significant”此处宜作“显著/重大”，与下文“速率越高，就越不正确”呼应；“有意义的”略偏。
4. **L66**“那些正确的、陌生的定律” ← “the correct but unfamiliar law”（单数）；且“等等之类”相对“and so on”多一层冗余（等等/之类）。不排除是原译，是否动请确认。
5. **L48**“令人惊讶、简单、而又非常奇特的图象” ← “the wonderful, simple, but very strange patterns”。此语境“patterns”指模式/规律，“图象”偏视觉；也可能是原书译法。
6. **L72**“比较奇特” ← “more wonderful”。wonderful 通常作“奇妙/精彩”，与“strange（陌生/奇怪）”义近的“奇特”可能削弱 exciting／wonderful／fun 的三层递进；仅标注。
7. **L26**“这有助于你们对本学科产生一种切身的感受” ← “to help us develop a ‘feel’ for the subject”。英文“us”含作者，中文改为“你们”并加“切身”；译法可商榷。
