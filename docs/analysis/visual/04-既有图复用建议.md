## 9. 不建议做的事（避免踩坑）

1. **不要重画现有 343 张图**：它们是原书插图的矢量重绘，风格统一、印刷质量好；重画成本远高于收益，且容易走样。只补“缺的图”和“读图提示”。
2. **不要给每一节都硬塞图**：110 个无图节里多数是短节（平均 1402 字），真正需要图的是其中 36 个“>1500 字且无图无表”的长节（见 02 号文件）；其余短节保持纯文字更紧凑。
3. **不要用“图+文件名”当图注**：现有 74.6% 的图注就是这么来的，这是本次要改的主要对象，新增图不要复制这个模式。
4. **不要动 `Figures/` 目录的命名**（除 §3 建议的两个改名外）：文件名被 `\includegraphics` 直接引用，批量改名需全库同步，风险大于收益。
