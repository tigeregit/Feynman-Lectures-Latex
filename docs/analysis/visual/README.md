## 方法（可复算）

全部由 **`tools/audit_figures.py`**（Python3 标准库 + `pdfinfo`）生成：

```bash
cd Feynman-Lectures-Latex
python3 tools/audit_figures.py          # 全量：需要 pdfinfo，约 4 秒
python3 tools/audit_figures.py --no-pdfinfo   # 跳过 PDF 尺寸读取（更快）
```

### 计数口径（与任务给定事实逐条校验过）

- **汉字数**：节正文中的 CJK 字符数，不含 `\section{}` 标题行、不含注释。校验：ch2 §量子物理学 3049、ch4 §能量的其他形式 2886、ch16 §相对论与哲学家 2861、ch12 §什么是力 2816、ch52 §空间与时间的对称性 2789、ch38 §哲学含义 2592、ch2 §引言 2440、ch46 §序与熵 2194、ch14 §功 2023；">1500 字且无图无表"=36 节、79,450 字——全部与任务背景一致。
- **图块**：`figure`/`wrapfigure` 环境；**编号图**：编译 aux 中 `\contentsline {figure}` 条数（含一个多 `\caption` 块里的多个编号图，不含 `\caption*`）。
- **表**：`\contentsline {table}` 条数（24）。
- **编译信息**：`_attachments/build-feynman/Chapters/**/*.aux`（与源文件 `diff -rq` 一致，未过期）提供图号、页码、所在节与 TOC 节起始页。
- **图尺寸**：`pdfinfo` 的 Page size 视作图形包围盒；PNG/JPEG 文件头解析像素。全书图 PDF 均无白边（抽样确认）。
- **版心**：`\textwidth=459.80pt`（16.22cm）、`\textheight=676.04pt`（23.85cm），取自编译 log；用于估算图在页面上的高度与占版比例。

### 一句话方法

**“先量化现状，再按‘文字可被结构替代’的程度排序，最后给出能编译的草图与可直接执行的工单。”**
不按“每章应该有几张图”的平均主义分配，而是优先找“>1500 字、无图无表、且内容是空间/流程/分类关系”的节——这类文字最可能被一张图或一张表压缩，收益也最容易验证。

## 关键数字速览

- 360 个图文件 → 351 个被用、**9 个孤儿**；294 个图块 → **343 个编号图**（50 个多面板块）、24 张表。
- 290 个编号节：**110 个完全无图（37.9%）**，103 个无图无表；**36 个“>1500 字且无图无表”（79,450 字）**。
- 图密度 0.55 图/页、777 字/页，但章间从 0.08（ch2）到 1.17（ch26）不等。
- 图注：**74.6% 与文件名逐字相同**；空 9 条、纯公式 23 条、仅标题 119 条、带出处仅 5 条。
- 引用：41 个图 label 没被 `\ref`（37 个靠手写编号提到、4 个正文完全没提）；另有 **65 处手写“图N.M”**、7 处手写“表N.M”；3 处确定错误（ch8 表编号错位 2 处、ch36 跨章引用 1 处）；3 处表 label 写在 caption 前。
- 图/表改造机会：P0 9 条（正文合计 26,215 字，按 03 的实例估算其中约 8–9 千字可被图/表压缩）、P1 14 条、P2 11 条。

## 已知局限（详见 01 §9）

1. 汉字数只计 CJK，含公式多的节会低估“视觉字数”；与既有事实已逐个校验。
2. 图版面占比是“纵向占位”代理（未计 wrapfigure 半宽），用于章间比较而非绝对值。
3. 节页码由 TOC 推算，跨页节可能有 ±1 页误差。
4. 硬编码引用只校验“编号是否存在/同章”，图号语义正确性靠人工抽查（已实锤 3 处错误，抽样 12 处一致）。
5. `03` 的 TikZ 草图是“手绘级示意”，用于表达结构而非最终插图；正式落地需按原书风格重画并统一线宽/字号。
