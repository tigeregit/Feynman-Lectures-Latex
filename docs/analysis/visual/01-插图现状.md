## 1. 数据来源与方法（可复算）

### 1.1 计数口径

| 量 | 口径 | 校验 |
|---|---|---|
| 汉字数 | 只统计节正文中的 CJK 字符（U+4E00–9FFF 等），不含 `\section{}` 标题行、不含注释 | 与任务给定的既有事实吻合：ch2 §量子物理学 = 3049、ch4 §能量的其他形式 = 2886、ch16 §相对论与哲学家 = 2861、ch12 §什么是力 = 2816、ch52 §空间与时间的对称性 = 2789、ch38 §哲学含义 = 2592、ch2 §引言 = 2440、ch46 §序与熵 = 2194、ch14 §功 = 2023；">1500 字且无图无表" 复算 = 36 节、合计 79,450 字 |
| 图块 | `figure` / `wrapfigure` 环境数 | 294 |
| 编号图 | 编译 aux 中 `\contentsline {figure}` 条数（= `\caption` 计数，`\caption*` 不计） | VolumeI 合计 343 |
| 表 | `\contentsline {table}` 条数 | 24 |
| 页数 | 章 aux 的 TOC 起始页 → 章末 `\setcounter{page}` | VolumeI 52 章合计 621 页（全书 PDF 695 页，差额为封面/序言/附录） |
| 图尺寸 | `pdfinfo` 读取 PDF 页面尺寸（本仓库的图 PDF 页面 = 图形包围盒，无白边）；PNG/JPEG 解析文件头像素 | 340 个 PDF 全部可读 |

### 1.2 规章核验

- 编译 aux 的章节副本与 `Chapters/` 源文件完全一致（`diff -rq` 只有 `.aux` 差异），所以 aux 中的图号/页码可直接用于审计。
- 版心 `\textwidth=459.80pt`（16.22cm）、`\textheight=676.04pt`（23.85cm），取自 `_attachments/build-feynman/Feynman Lectures on Physics.log`；用于估算图在页面上的实际高度。

### 2.3 版面尺寸风险（按声明宽度 × 纵横比估算）

- **无一张图会垂直溢出**：最高的是 ch2 §原子核与粒子 的「基本粒子」图，按 `width=0.65\textwidth` 估算高约 **22.6 cm**（占版心 95%），已接近“必须独占一页”的临界。
- 估算高度 < 2.5 cm 的**小图 54 个**（如 ch13「引力场中的闭合路径」0.83 cm、ch4「简单的起重机械」1.54 cm）——它们多为行内小示意图，本身合理，但若放大阅读（电子版缩放）会失真。
- 声明宽度以 `\textwidth` 比例为主（约占 2/3），固定 `cm` 宽度次之（5–6 cm 一档最多）。同一章内 `5cm/5.5cm` 与 `0.35–0.45\textwidth` 混用，导致图宽不统一（见 `data/figures-compiled.csv` 的「声明宽度」列）。

1. **图注被当成“文件题名”而不是“读图提示”**：74.6% 的图注与图片文件名逐字相同；读者看完图注仍不知道图里哪条线/哪个符号表示什么。典型如 ch1 的 10 张图注（`水蒸气`、`冰`、`盐在水中的溶解`）全是名词。

3. **纯公式图注**：ch22 两张图（22.1/22.2）图注为空或只有公式，正文却用「图\ref{...}」引用，属于“引用得到、读不懂”。
4. **出处仅 5 条**：ch23 的实验曲线图带文献出处，ch5/ch7 的天文照片（本应标注望远镜/版权来源）全部没有出处。
5. **`\footnotesize` 图注混排**：71 条图注自带 `\footnotesize`，导致同页图注字号不一致；另有跨行 `\\` + `\footnotesize` 的写法（ch20 陀螺图），风格不统一。

## 7. 图与版式：放置方式与阅读动线

- **放置方式**：`wrapfigure` 211 / `figure` 83。`wrapfigure` 占 72%，属于“文字绕图”风格；`figure` 中 `[htbp]` 50 个、`[H]` 28 个。主文件 `\usepackage[section]{placeins}` 使浮动体不跨节，实际版面较可控。
- **多面板**：50 个图块内含 2 个及以上 `\caption`（多为左右两幅小图），但**只有 8 张子图没有 label**；多面板子图普遍没有 (a)(b) 标注（正文只写“图 a/b/c”），读者对应成本高。
- **图-文距离**：253 个有 `\ref` 的图块中，正文引用点距图块起始行的中位数为 **6 行**，P10 = −2 行、P90 = 8 行——总体“文图相邻”，动线合理；但仍有 41 个图块没有任何 `\ref`，只能靠读者自己找。
- **跨页/超高图**：仅「基本粒子」一张估算高 22.6 cm（版心 95%），`[htbp]` 下容易单独占页、留下半页空白；无真正溢出。

命名本身不影响编译，但带来两个维护问题：
1. **“文件名即图注”的写法让图片名承担了说明文字的功能**，一旦要改图注就得同时改文件名（`\includegraphics` 路径跟着变），改造成本高；
2. 长中文文件名在 `\includegraphics` 里跨行、易出错，且不同人命名风格不统一（`24-6`、`51-4`、`10的逐次平方根` 混排）。

## 9. 已知局限

1. **汉字数口径**：只统计 CJK 字符、不含公式/行内符号，因此含大量公式的节（如 ch8 §速率）字数会略低于“视觉字数”；与任务给定的既有事实已逐个校验一致。
2. **图尺寸**：`pdfinfo` 的 Page size 视作图形包围盒；若某 PDF 带白边，估算高度会偏大（本仓库图 PDF 均为紧贴包围盒，抽样 5 个确认）。
3. **图版面占比**：用“估算高度累计/版心高”近似，未计宽度方向（wrapfigure 只占 35–45% 宽），所以是“纵向占位”的代理指标，不是真实面积；章间比较可用，绝对值不可当精确数。
4. **页码映射**：按章 aux 的 TOC 节起始页 + 下一节起始页推算节页码范围，跨页节可能把图归到前一节（误差 ±1 页）。
5. **硬编码引用语义**：脚本只能判定“编号是否存在/是否同章”，无法判断“图3-1 指向的图是否语义正确”；已对 3 处确定错误做实锤，其余 65 处按编号存在处理（抽样 12 处人工核对一致）。
6. **图注质量**：按“有无标点/长度”自动分类，会把“长但仍是名词短语”的图注算作“有解释”（如 ch5 的 8/10 需要人工再筛）。
7. **VolumeII/III**：各只有 1 章节选（V2-1 2912 字、V3-1 797 字），相关结论只作提示，不纳入 VolumeI 统计口径。
