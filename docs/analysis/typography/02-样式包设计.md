## 2. 加载方式与兼容性顺序

```latex
\documentclass[UTF8,12pt,a4paper,twoside]{ctexbook}
% ... 主文件原有宏包（indentfirst, siunitx, ..., caption, placeins, hyperref）
% ... 字体与 geometry 设置
\usepackage{readability}     % ← 必须放在导言区最后一行
\begin{document}
```

- 前提：文档 class 为 `ctexbook`（或至少加载 ctex/xeCJK）；用 XeLaTeX 编译。
- 样式包**自己会加载**：`xcolor, geometry, etoolbox, ulem, xeCJKfntef, titlesec, tcolorbox(skins,breakable), marginnote, fancyhdr, caption, bookmark, hyperref`；已加载的宏包不会重复加载（无选项冲突）。
- 放在 `hyperref` 之后加载最稳（本包内部会 `\RequirePackage{hyperref}`，但推荐显式顺序）；`\AtBeginDocument` 里统一覆盖链接颜色，因此文档自己的 `\hypersetup{...}` 不会盖掉版式包设置。
- 全书集成方式（试编译已验证）：复制主 tex，在 `\begin{document}` 前加一行 `\usepackage{readability}`，其余不动。

## 3. 选项

| 选项 | 默认 | 作用 |
|---|---|---|
| `mode=color` | ✅ 默认 | 彩色版：深蓝强调色、浅灰底框、淡蓝链接 |
| `mode=mono` | | 黑白打印版：所有颜色降为灰阶（强调色→35% 灰、框底→240 灰、链接→纯黑），无彩色依赖 |
| `skim` | | 速读版：`optional` 环境**整段隐藏且不占版面**（同一份正文可出"全本/速读本"两个 PDF） |
| `screen` | | 屏幕阅读：行距 1.30 → 1.34（+3%），其余同 color；**默认不加**，避免页数膨胀 |

未知选项只发 `PackageWarning`，不会报错（便于内容同学本地实验）。

## 6. 对外接口总表

> 正文作者只需要这些宏；**不要**在正文里写 `\textbf{\color{...}}` 之类的样式命令。

### 6.1 强调体系

| 接口 | 语法 | 效果 | 注意 |
|---|---|---|---|
| `\runin{标题}` | `\runin{三种检验方法}正文…` | 段内小标题：黑体+强调色，`标题．` 后接正文，自动另起段 | 建议写在段首；会结束上一段 |
| `\term{术语}` | `\term{基本概念}` | 术语首次出现加粗 | 预留索引占位（将来可扩为 `\index{}`）；不改变文字 |
| `\enterm{英文}` | `\enterm{kinetic energy}` | 小号英文对照 | 放括号里由作者决定 |
| `\keyidea{句}` | 行内：`…\keyidea{关键判断}…` | 左侧短色条 + 加粗，**不断段**，可句中使用 | 不可放进数学公式内（`\rule` 需要水平模式） |
| `\pullquote{引文}` | 独立命令，前后自动分段 | 楷体（STKaiti）+ 上下细线，左右缩进 2em | 适合费曼金句 1–2 处/节 |
| `\uwave{...}` | **不变**（全书 455 处无需改） | 重定义为「细下划线」：彩色版深蓝、黑白版纯黑；由 `xeCJKfntef` 的 `\CJKunderline` 实现，中文断行/标点正常 | 原 `ulem` 的波浪线在 XeLaTeX+CJK 下几乎不可见且与字底重叠；如需恢复波浪可改回 `\CJKunderwave` |

### 6.2 结构化环境

| 接口 | 语法 | 效果 | 注意 |
|---|---|---|---|
| `summarybox` | `\begin{summarybox}[本节要点] … \end{summarybox}` | 浅灰底 + 左侧色条；标题可选，**默认「小结」** | breakable，可跨页；内容支持 itemize/公式 |
| `keybox` | `\begin{keybox}{关键概念：可逆过程} … \end{keybox}` | 强调色浅底 + 描边 + 标题条 | 标题**必填** |
| `conceptmap` | `\begin{conceptmap}[标题] … \end{conceptmap}` | 浅色边框占位框（默认标题「概念图」），内放 TikZ/表格均可 | **不自带 caption、不自动编号**；来源用 `\figsource` |
| `optional` | `\begin{optional} … \end{optional}` | 正常版：段首灰色「〔选读〕」标记，照常排版；`skim` 版：整段隐藏 | skim 下内容被整体捕获丢弃，内部 `\label` 会失效（如选读段有被引用标签，请移到正文） |
| `\chapterintro{内容}` | 紧跟 `\chapter` 后使用 | 章首导读框（默认标题「本章导读」，breakable） | 内容可含 `\keyidea` 等行内宏；不要放进移动参数 |
| `\readingpath{内容}` | `\chapterintro` 之后 | 「阅读路径 ▶ …」一行小字提示 | — |
| `\aside{内容}` | 行内任意位置 | 24mm 宽页边注（marginnote，小号灰字、raggedright） | 不能用在 `\caption`、`\section` 等移动参数里；过长会自动多行并可能被浮动体挪页，属正常；一段里不要连续放 2 个以上 |
| `\figsource{来源}` | 放在 `\caption{...}` 内或框内 | 行内小号灰字「（来源：…）」 | 放在 caption 内时建议放句末；不自动编号 |

### 6.3 图表与标题

| 项目 | 新样式 |
|---|---|
| 图注 | `caption`：`small` 字号、标签（图 7.1）灰色、`labelsep=quad`、单行居中、间距 6pt |
| 图表编号 | **沿用 ctexbook 默认「按章编号」**：`图 7.1`、`表 6.1`（**刻意不改成 `图 7-1`**，理由见 §8 DC-2） |
| 章标题 | titlesec `display`：居中，`第\chinese{chapter}章`（强调色，黑体）+ 章名（`\Huge` 黑体）+ 下方 56pt×1.2pt 短色条 |
| 节标题 | 左对齐，编号强调色，标题黑色，`\large` 加粗 |
| 小节标题 | 左对齐，编号强调色，`\normalsize` 加粗（全书当前 0 个 `\subsection`，为内容改造预留） |
| 页眉 | 偶数页：外侧页码 + 内侧章名；奇数页：内侧节名 + 外侧页码；`plain` 页（章首）无页眉、页脚居中页码 |
| 超链接/书签 | `colorlinks` 淡蓝；书签数字编号、默认展开一级、depth=2；`pdfborder=0 0 0` |

## 8. 关键设计决策记录

### DC-1　行宽取 161mm 而不是 155mm
Lead 最初建议 `textwidth≈155mm + marginparwidth 24–28mm`。实测 155mm 版本：**738 页（+6.2%）、6 个 Overfull**，其中 4 个来自 Ch19/Ch26 的定宽表格（`\setlength{\tabcolsep}{10mm}`，表格自然宽 157–160mm，在 155mm 版心下被挤破 6–14pt）。改回 **161mm（38.2 字）+ 内 21/外 28mm + 页边注 24mm**：**718 页（+3.3%）、仅 2 个 Overfull（1 个是基线原有）**，且 161mm 仍在 30–40 字舒适区。→ 采用 161mm。

### DC-2　图/表编号保留「图 7.1」点号（刻意不变）
正文中存在大量**硬编码编号**（grep 统计，`Chapters/` 下）：

| 形式 | 数量 | 分布 |
|---|---|---|
| `图N.M` 硬编码 | **58 处** | Ch2×2, Ch4×7, Ch5×9, Ch6×20, Ch7×13, Ch8×3, Ch20×3, Ch36×1 |
| `表N.M` 硬编码 | **11 处** | Ch6×2, Ch8×9 |
| `图N-M` 硬编码 | 10 处 | Ch3×4, Ch23×1, Ch29×2, Ch30×1, Ch36×1, Ch38×1（原书即与点号图注不一致） |
| `表N-M` 硬编码 | 1 处 | Ch23 |

若把 `\thefigure` 改成连字符 `7-1`，上述 58+11 处正文引用会与图注错位（如正文「图7.1」对图注「图 7-1」）。因此**保留 ctexbook 默认按章编号**，样式包只改图注字号/颜色/间距与来源。
> **低风险后续改造项（P1，内容/工具层）**：把硬编码 `图N.M`/`表N.M` 批量替换为 `图~\ref{figure:...}`/`表~\ref{table:...}`（需先核对 335 个 figure label 与图注的对应关系），编号格式就变成"可自由升级"的了，同时 PDF 内链生效。当前版本不做，避免改正文。

### DC-3　ctexbook + titlesec 兼容
- 实测 `ctexbook + titlesec` 可共存：`\chapter*`（译者序、附录等星号章）不会打印「第零章」；`\tableofcontents` 中章条目仍为中文「第二章 基本物理」；`\part` 页未被 titlesec 接管、样式不变（已渲染核对）。
- 章标题不用 ctex 的 `\ctexset` 实现（避免与 titlesec 双写），统一走 titlesec；`\chinese{chapter}` 负责中文数字。
- 曾经的一个坑：标题字体若用 `\sffamily`，Latin Modern Sans 缺 `ω`（U+03C9），Chapter34 节标题「ω，k四元矢量」会缺字。→ 标题字体改为「中文黑体 + 拉丁沿用正文字体（Times New Roman，含希腊字母）」，全书 Missing character **0**。

### DC-4　`\uwave` 重定义而不是改正文
全书 455 处 `\uwave`。原 `ulem` 的波浪线在 XeLaTeX+CJK 下渲染极淡、且波形压在字底。样式包用 `xeCJKfntef` 的 `\CJKunderline` 重定义 `\uwave`（彩色=深蓝细线、黑白=纯黑细线），**正文一个命令都不用改**；断行、标点、脚注场景正常。若将来想恢复波浪效果，可改为 `\CJKunderwave`（一行改动，样式集中）。

### DC-5　页眉页码放切口（外侧）
偶数页页码在左侧、奇数页在右侧（外侧），章/节名靠订口；`plain` 页无页眉。这与中文图书惯例一致，也避免页码与章名挤在同一侧。

### DC-6　附录 `\leftmark` 兜底（主文件集成清单）
`\chapter*{附录}` 不更新 `\leftmark`。当前全书附录只有 1 页且是 `plain` 首页（无页眉），实测看不到残留章名；但**如果未来附录跨页**，后续页会显示上一章的 `\leftmark`。→ 建议主文件集成时在 `\chapter*{附录}` 后加一行：
```latex
\markboth{附录}{}
```
这条属于主文件改动，样式包不强行 patch `\chapter*`（避免与 ctex/titlesec 交互出问题）。

### DC-7　「不破坏既有 \ref / 表格 / chemfig」
- `\ref`：全书 1101 个 `\ref`、1120 个 `\label`，试编译 **0 undefined reference**；图号统一由 `\thefigure` 生成，引用/图注天然一致。
- 表格：`booktabs/longtable/tabularx` 全部继承；只在样式层加 `\arraystretch=1.12`（不改变定宽表格的自然宽度）。
- chemfig/tikz/siunitx：未改动其样式；`tcolorbox` 与 `tikz` 共存、`conceptmap` 内可直接放 TikZ。
- `caption` 二次设置：主文件已 `\usepackage[justification=centering]{caption}`，样式包用 `\captionsetup{}` 覆盖，无 option clash。

## 10. 已知限制与注意事项

1. `\keyidea` 不适用于数学公式内部（需要水平模式；公式里请用 `\keyword` 之外的普通强调或放到公式前后）。
2. `\aside` 不能出现在 `\caption`、`\section` 等移动参数/Fragile 命令里；页边注内容过长会多行、可能被浮动体"挤"到相邻页（marginnote 的已知行为）。
3. `optional` 在 `skim` 模式下由 environ 捕获丢弃：内部若含 `\label` 会失效；不要放 `verbatim`/`lstlisting` 等改变 catcode 的内容。
4. `\pullquote` 是块级命令（自动分段），不要在行中间使用。
5. 章首导读框 `\chapterintro` 若过长可能把章名页和正文挤散；建议 ≤5 行。
6. 页边注宽度 24mm 是几何硬约束（外白 28mm）；如需加宽，必须同步加大外侧白边/收版心（会增页数）。
7. 样式包只保证在 ctexbook + XeLaTeX 下工作；pdfLaTeX 不支持（xeCJKfntef/marginnote/字体依赖）。
