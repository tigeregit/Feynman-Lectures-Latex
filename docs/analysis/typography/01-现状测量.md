# 01 · 现状测量：现有版式到底"紧"在哪里

> 任务：task-3「版式原型」· style-eng
> 实测环境：macOS + TeX Live 2026（XeTeX 3.141592653-2.6，latexmk），字体 Songti SC（SimSun 缺失自动回退），原版式 = 主文件 `Feynman Lectures on Physics.tex` 导言区（ctexbook 12pt A4 twoside + geometry `scale=0.8` + `bindingoffset=8mm`）。
> 复现命令（本仓库内）：
> ```bash
> cd preview/style-demo
> xelatex -interaction=nonstopmode -output-directory=build measure-baseline.tex     # 原版式
> xelatex -interaction=nonstopmode -output-directory=build measure-readability.tex  # 新版式
> grep -A20 'RD-.*MEASURE' build/measure-*.log
> ```

## 1. 单位与口径

- TeX pt → mm：`1 mm = 2.845276 pt`（`1 in = 72.27 pt`）。**与 Lead 消息里的 mm 数存在约 0.4% 偏差**（Lead 按 `1 pt = 0.3528 mm` 换算，得 162.2 mm / 238.5 mm；按 TeX 标准换算为 **161.6 mm / 237.6 mm**）。pt 原始值完全一致，以下 mm 按标准换算，pt 值可逐项核对。
- "每行汉字数"口径：`每行汉字数 = textwidth / 1em`，12pt 正文下 1 个全角汉字宽 = 12pt（实测 Songti SC 全角字宽与字号相等）。行内留白/标点会使实际字数略少（约 ±1 字）。
- "每页行数"口径：`textheight / baselineskip`，理论值；实际页因标题/图表浮动而不同。
- 所有数字来自 `measure-baseline.log` / `measure-readability.log` 的 `\typeout`，非目测。

### 2.1 与"中文阅读舒适区"的对照

| 维度 | 舒适区（任务给定 / 通行经验） | 现状 | 结论 |
|---|---|---|---|
| 行宽 | 30–40 汉字 | **38.3**（161.6mm） | 在区间内、偏上；**不必改行宽**（改动会破坏定宽表格，见 03 报告） |
| 行距 | 1.4–1.6 × 字号 | **1.571**（18.85pt / 12pt） | **已在舒适区**；"观感偏紧"主因不是行距，而是段间距=0 与行长偏长，**不建议加大 linespread**（会直接抬高页数） |
| 每页行数 | 30–40 行 | **35.9** | 合理 |
| 段间距 | 0.25–0.35 em | **0** | ❌ 主要硬伤：连续段落视觉连成一片，"文字墙"感的主要来源 |
| 字号 | 10.5–12pt | 12pt | 合理 |
| 标题层级 | 章 > 节（> 小节） | 仅章/节两级，均居中、无颜色/线/间距区分；全书 0 个 `\subsection` | ⚠ 层级弱，扫读时缺少锚点 |
| 强调手段 | 可辨识 | `\uwave` **455 处**，在 100–150dpi 渲染下几乎不可见（波形极淡且与字底重叠） | ❌ 强调体系基本失效 |
| 页边注 | 可用 | `\marginparwidth`(30.9mm) > 外白(20.1mm) | ❌ 不可用；content-pilot 已复现"译者注被裁在左页边缘"（这是**参数本身**导致的，不是用法问题） |
| 图注 | 小号、标签区分、有来源 | 与正文同字号、编号后冒号、无来源字段 | ⚠ 弱 |
| 页眉 | 章/节名 | 仅章名+页码（ctexbook `headings`），无节名 | ⚠ 可补 |

> 结论：**行宽与行距其实已经合格**（这一点修正了任务背景里"行距偏紧"的初始判断）；真正需要动的是 **段间距、强调可见性、标题层级、页边注可用性、图注/页眉** 这 5 项，以及 `\uwave` 的可见性。这也决定了新版式的策略：**不动 linespread、只微调行宽**（161.0mm，−0.4%），把预算花在段间距与结构元素上，从而把全书页数增量控制在 3.3%（见 03）。

## 3. 新版式实测（readability.sty）

| 参数 | 原版式 | 新版式 | 变化 |
|---|---|---|---|
| `\textwidth` | 459.80pt / 161.6mm / 38.3 字 | **458.09pt / 161.0mm / 38.2 字** | −0.4% |
| `\textheight` | 676.04pt / 237.6mm | **676.04pt / 237.6mm** | 不变 |
| `\baselineskip` | 18.85pt（1.571×字号） | **18.85pt（1.571×字号）** | 不变 |
| 每页行数（理论） | 35.86 | **35.86** | 不变 |
| `\parskip` | 0 pt plus 1pt | **3.60pt plus 0.72pt minus 0.36pt（0.30em）** | +3.6pt/段 |
| `\parindent` | 24pt | 24pt（2em） | 不变 |
| 内 / 外侧页边距 | 28.3 / 20.1 mm | **21.0 / 28.0 mm** | 外白 +7.9mm（为页边注让位，订口仍 21mm） |
| `\marginparwidth` | 88pt（30.9mm，溢出） | **68.29pt（24.0mm）** | 可完整落在外白内（28 − 2.5 − 24 = 1.5mm 余量） |
| `\marginparsep` | 7pt | 2.5mm（7.11pt） | — |
| 页眉高/间距/页脚 | 12pt / 6.99mm / 10.55mm | 14pt / 6.1mm / 10mm | 页眉容纳小号中英混排 |
| 正文顶部位置 | 67.60pt（23.76mm） | 67.43pt（23.70mm） | 基本不变（−0.17pt） |
| 每行汉字数 | 38.3 | 38.2 | 在舒适区内 |

其余新增项（不在"测量"范围，见 02/03）：`\linespread` 默认仍 1.30（`screen` 选项 1.34）；titlesec 章/节/小节标题；页眉章名/节名 + 外侧页码；图注 small + 标签灰 + `\figsource` 来源；hyperref 淡色链接 + 书签展开。

## 4. 测量方法备注

- 直接读 `\textwidth` 等寄存器比用 `\layout` 目测可靠；基线值同时被 Lead 的独立实测确认（pt 值一致，mm 换算口径不同，见 §1）。
- `\marginparwidth` 虽然给了 88pt，但 TeX 排页边注时使用"版心右缘 + `\marginparsep` 起、宽 `\marginparwidth`"，与外侧白边实际可用宽度无关 → 必须显式把 `marginparwidth` 收到"外白 − marginparsep"以内，这也是新版 geometry 的设计约束。
- 原版式 `\flushbottom`（book 类 twoside 默认）导致全书 **187 处 Underfull \vbox**（版面被强行拉伸）；新版 `\raggedbottom` 后为 **0**（详见 03）。
