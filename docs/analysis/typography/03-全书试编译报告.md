## 5. 为什么 Underfull 从 187 → 0

- 基线 187 条 Underfull **全部是 `\vbox`**（`grep 'Underfull' | sed` 统计：187 vbox / 0 hbox），来自 book 类 twoside 默认的 `\flushbottom`：页面内容不满时 TeX 强行拉伸行距填满版心，必然报 underfull。
- 新版式 `\raggedbottom` 后不再拉伸页底，这 187 条全部消失；同时 `\clubpenalty/\widowpenalty=10000` 抑制孤行，页数只增加约 1%。
- 这不是"压掉警告"：页底留白是中文正文的通行做法（保证行距一致），比"强行撑满 + 行距忽宽忽窄"更利于阅读。

## 7. 编号格式决策（重要）

**新版式刻意保留 ctexbook 默认的「按章编号 + 点号」：`图 7.1`、`表 6.1`。**

- 正文存在 **58 处硬编码 `图N.M`**（Ch2×2、Ch4×7、Ch5×9、Ch6×20、Ch7×13、Ch8×3、Ch20×3、Ch36×1）与 **11 处硬编码 `表N.M`**（Ch6×2、Ch8×9）；若改成连字符 `图 7-1`，这些正文引用会与图注错位。
- 另有 10 处源文本自带 `图N-M`、1 处 `表N-M`（Ch3/Ch23/Ch29/Ch30/Ch36/Ch38），是**原书既有的不一致**（与点号图注本就不匹配），本次不引入新问题、也不在本任务中修改正文。
- **P1 后续低风险改造（内容/工具层，非本任务）**：把硬编码 `图N.M`/`表N.M` 批量换成 `\ref{figure:...}`/`\ref{table:...}`（需先核对 335 个 figure label 与图注对应关系），之后编号格式即可自由升级，且 PDF 内链生效。

## 8. 页数控制建议

当前 +3.3% 已达标；若将来合并「内容层改造」（分段/列表/框类会进一步增页）后需要压页数，按性价比排序：

1. **段间距**：0.30em → 0.25em（约省 0.5–1% 页数；仍能区分段落）。
2. **章前间距**：`\titlespacing*{\chapter}` 的 `afterskip` 40pt → 32pt（每章省 ~2–3 行，52 章合计 ~1 页）。
3. **`\raggedbottom` 保留**（不要退回 `\flushbottom`，否则 Underfull 复现且观感更差）。
4. **不要加大 linespread**：1.30 是当前页数的关键锚点，+0.05 行距约 +3.5% 页数。
5. **不要收回版心到 155mm**：会挤破 4 个定宽表格（§4），且 +6.2% 页数。若确有需要，应先把 Ch19/Ch26 的 4 个表 `\tabcolsep` 从 10mm 改到 9mm（本任务约束不改 Chapters，只给建议）。
6. **页边注宽度 24mm 是几何硬约束**：再宽必须收版心或加外白，均会增页。
