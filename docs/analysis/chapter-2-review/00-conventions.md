## 2. 问题分类与严重度

分类（type）：`错字`、`漏字/多字`、`漏句/漏译`、`重复`、`标点`、`数字/量纲`、`术语/物理`、`表格/图`、`LaTeX/结构`。

严重度：
- **高**：改变物理含义 / 数字或表格数值错误 / 漏句漏段 / 重复导致语义错乱 / 编译或引用错误
- **中**：明显的 OCR 错字、缺字、标点断裂，读者需要停顿猜测才懂；术语误译但结论仍对
- **低**：纯排版空格、不影响理解的标点/用词瑕疵、译法可商榷
