## 2. 硬约束（违反即返工）

1. **零删改原文**：不删句、不删词、不改词、不调整语序、不修原文错字（如"运动得多块"照录）；只允许**插入**段落分隔、结构标记、新增文字块（见 §4）。
2. **新增文字必须标记**：所有新增文字/新增图表用成对注释包住，校验工具据此剔除：
   ```latex
   %<<<NEW
   \runin{这里是小标题}
   %>>>NEW
   ```
   标记行必须是 LaTeX 注释（`%` 开头），不得影响排版。
3. **只使用 `styles/readability.sty` 提供的语义宏**，禁止手写字体/颜色/间距：
   `\chapterintro`、`\readingpath`、`\runin`、`\term`、`\keyidea`、`\pullquote`、`summarybox`、`keybox`、`conceptmap`、`optional`、`\aside`、`\figsource`、`\fighint`。
4. **不修改**：`\section{}` 标题、公式、图表编号、`\label`/`\ref` 语义、其他章、主 tex、`styles/readability.sty`。
5. 不执行 `git commit` / `git checkout` / `git stash`；分支保持 `feat/reading-efficiency`。
6. 不改动 `Figures/`；不新增外部图片（新增示意图只用 TikZ）。

## 3. 每章改造清单与配额

| 项 | 要求 | 配额 |
|---|---|---|
| A 章首导读 | `\chapterintro{一句话定位 + 3–5 条本章要点 + 与前后章关系}`；随后 `\readingpath{速读/精读路径}` | 1 组/章 |
| B 段落切分 | 目标每段 ≤250 字；只在语义边界切；每段保留 ≥2 句 | 见各章长段清单 |
| C 列表化 | 显式枚举（第一/第二/（1）（2）/首先其次最后）→ `enumerate`/`itemize`；**列表项内保留原句**，原有序数词可放入 `\item[第一，]` 标签 | 每章 2–6 处 |
| D 段内小标题 | `\runin{标题}`，≤12 字，内容性路标（非"总之""其他"） | 每章 4–8 个 |
| E 术语/关键句 | `\term{}` 首次出现的关键术语；`\keyidea{}` 关键判断句；均只包裹原有文字 | 术语 6–12 个；关键句 2–5 句 |
| F 小节小结 | `summarybox`：仅对 **≥1200 字**的节，3–4 条、每条 ≤28 字，只做提炼不加新知识 | 按节字数（见 §5） |
| G 页边注 | 译者注 `\footnote{}` → `\aside{}`（文字原样、位置不变） | 有则改 |
| H 选读标记 | 真正的离题旁白才标 `optional`，≤本章 8% 文字；没有就不标 | 0–3 段/章 |
| I 现有图 | 每章挑 1–2 张复杂图，在图注后加 `\fighint{一句读图提示}`（新增文字，标记） | 1–2 条/章 |
| J 新增图示 | 每章 **1 个** 新增图/表（TikZ 或 table），放最需要视觉锚点的节；整块用 NEW 标记 | 1 个/章 |
| K 引文 | `\pullquote` 可选，最多 1 处；**风险高（重复正文会破坏零删改校验），默认不做** | 0（除非已验证通过） |

## 4. 新增文字标记与口径

- **必须标记**：`\chapterintro`、`\readingpath`、`\runin` 标题、`summarybox` 整块、`conceptmap` 整块、新增 `table` 整块、`\fighint`、`\figsource`（如新增）。
- **不要标记**（原文文字，只是换呈现方式）：`\term`/`\keyidea` 包裹的原句、列表化后的原句、`\footnote`→`\aside` 的文字、`optional` 包裹的原文段落。
- 新增文字总量控制：**≤ 本章原文汉字的 15%**（工具会统计）。

## 5. 校验与编译（每章必须全部通过）

### 5.1 零删改校验（必须 PASS）

```bash
cd Feynman-Lectures-Latex
python3 tools/verify_chapter.py 1        # 章号；默认从 git main 取原文
python3 tools/verify_chapter.py 26
python3 tools/verify_chapter.py 52
```

- PASS 输出示例：`[PASS] Chapter1: 内容字符 11509/11509 完全一致（零删改）`
- FAIL 会打印首个不一致位置与上下文 → 修到 PASS 为止；**不要改校验脚本**。

### 5.2 统计

```bash
python3 tools/chapter_stats.py 1         # Markdown 表格
python3 tools/chapter_stats.py 1 --json  # JSON
```

把输出写进 `docs/analysis/chapter-N-notes.md`。

### 5.3 单章编译检查

复制模板到自己的目录并改章号：

```bash
mkdir -p preview/chapter-1/build
cp preview/transformed-check/check-template.tex preview/chapter-1/check.tex
# 编辑 check.tex：把 \input 的章号改成你的章
cd preview/chapter-1
xelatex -interaction=nonstopmode -output-directory=build check.tex
xelatex -interaction=nonstopmode -output-directory=build check.tex
```

通过标准：**0 error、0 overfull、0 missing character**（warning 可接受，需在 notes 说明）。产物留在 `preview/chapter-N/build/`（已 gitignore，不提交）。

## 6. 交付物（每人）

1. `Chapters/VolumeI/ChapterN.tex` —— 改造后正文（含 `%<<<NEW` 标记）
2. `preview/chapter-N/check.tex` + `build/check.pdf` —— 单章编译样张
3. `docs/analysis/chapter-N-notes.md` —— 改造说明：
   - 改造前后统计表（`chapter_stats.py` 输出）
   - 零删改校验结果（PASS + 字符数）
   - 新增文字清单（导读/小结/小标题/图注提示/新增图表，各多少字）
   - 列表化、切段、runin、term、optional 的具体位置（章/节/行号）
   - 编译结果（0 error / overfull / missing char）
   - **需人工复核点**（如：某处切分是否合理、某术语选择、新增图表是否准确）
   - 原文错字/疑点清单（照录未改，供后续校对）
4. `send_message` 给 lead：章号、PASS 结果、统计摘要、新增文字占比、编译状态、复核点。

## 8. 质量红线

- 校验 FAIL 的提交一律不接受；
- 新增文字不得超过 15%，导读/小结不得写成"教科书条目"（保留费曼口语体，只做提炼）；
