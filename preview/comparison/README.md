# 三章对比册：原版 vs 阅读效率版

本目录是「原版（695 页）」与「阅读效率版（726 页）」的并排对比册，覆盖本次试点的三章：

- **第 1 章**《原子的运动》（全书首章）
- **第 26 章**《光学：最短时间原理》（52 章正中）
- **第 52 章**《物理定律的对称性》（全书末章）

## 怎么看

每页左侧是**原版**、右侧是**阅读效率版**，页眉标注两版各自的印刷页码。建议按顺序看：

1. **章首**：右侧新增「本章导读」框（一句话定位 + 3–5 条要点 + 与前后章关系）和「阅读路径」（速读/精读两条线）；
2. **正文**：段间距、段内小标题（`\runin`，蓝色加粗）、术语加粗、关键句（左侧竖线）、列表（原书没有列表，现在把"第一/第二/首先/其次"改成了编号列表）；
3. **页边**：译者注从脚注移到页边注（灰色小字），不打断正文；
4. **图/表**：图注后新增「读图提示」；第 52 章新增「对称操作 × 改变量 × 守恒量 × 反例」对照表（表 52.2）；
5. **节末**：「小结」框 3–5 条，可当复查清单；
6. **整体**：页眉显示章名/节名 + 外侧页码；`\uwave` 强调改为可见细下划线；新增 `conceptmap` 概念图（第 1 章尺度阶梯、第 26 章三情形最短时间）。

## 复现

```bash
# 1) 构建阅读效率版全书（新版式 + 三章改造）
bash tools/build_reading_efficiency_book.sh

# 2) 生成对比册（原版 PDF 用 _attachments 中的基线构建）
python3 tools/make_comparison.py \
  --before "_attachments/build-feynman/Feynman Lectures on Physics.pdf" \
  --after  "_attachments/build-feynman/reading-efficiency/Feynman Lectures on Physics.pdf" \
  --out    preview/comparison
```
